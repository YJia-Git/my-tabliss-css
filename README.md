# Tabliss Animated Background

A simple animated gradient CSS background for Tabliss new tab extension.

### 🔍 Folder Details

- `src/`: Source code for development (HTML + CSS)
- `dist/`: Final, minified, or optimized CSS for use in Tabliss
- `examples/`: Demos or alternative background variations

## Usage

1. Open Tabliss settings → Custom CSS
2. Paste the contents of `src/animated.css`

## 🚧 Status

- `src/` contains the working background code (index.html + style.css)
- `dist/` and `examples/` are currently empty – reserved for future use
